# HerGuide QA Test Cases

Manual testing portfolio for the HerGuide web application.

## Project Under Test

HerGuide is a web application that provides centralized access to resources related to women's safety, healthcare, legal aid, career and mental wellness.

## Testing Scope

- Search functionality
- Category filtering
- Bookmark functionality
- Emergency quick-help links
- AI Resource Assistant
- Responsive behavior
- Input validation
- Positive and negative test scenarios
- Edge cases

## Testing Approach

The application is tested using manual testing techniques including:

- Functional Testing
- Positive Testing
- Negative Testing
- Regression Testing
- Smoke Testing
- Exploratory Testing

- Google Chrome

- Browser Developer Tools
